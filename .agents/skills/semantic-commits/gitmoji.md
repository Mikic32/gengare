# Extra gitmojis

Type emoji comes from SKILL.md. These are **suffixes** (or a replacement only when the type table has no fit).

Source: https://gitmoji.dev

## Common suffixes

| Emoji | Code | Use |
| --- | --- | --- |
| ⬆️ | `:arrow_up:` | upgrade dependency |
| ⬇️ | `:arrow_down:` | downgrade dependency |
| ➕ | `:heavy_plus_sign:` | add a dependency |
| ➖ | `:heavy_minus_sign:` | remove a dependency |
| 📌 | `:pushpin:` | pin a version |
| 🔥 | `:fire:` | delete code or files |
| ⚰️ | `:coffin:` | remove dead code |
| 🚚 | `:truck:` | move or rename |
| 💥 | `:boom:` | breaking change |
| 💄 | `:lipstick:` | UI / style files |
| 🚨 | `:rotating_light:` | linter / compiler warnings |
| 🔒 | `:lock:` | security or privacy |
| 🏷️ | `:label:` | types |
| 🩹 | `:adhesive_bandage:` | tiny non-critical fix |
| 🚑️ | `:ambulance:` | critical hotfix |
| 📱 | `:iphone:` | responsive / device UI |
| 🏗️ | `:building_construction:` | architecture |
| 🙈 | `:see_no_evil:` | `.gitignore` |
| 🍱 | `:bento:` | assets |
| 💡 | `:bulb:` | comments |
| 🧵 | `:thread:` | concurrency |
| 🦺 | `:safety_vest:` | validation |

Example from the gist:

```
👷 build(android): Bump Gradle 8 to 9 ⬆️
```
